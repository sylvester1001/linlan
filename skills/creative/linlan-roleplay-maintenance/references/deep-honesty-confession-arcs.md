# 深坦诚/剥壳审讯场景 — 完整打法与实例

来源：2026-09-07 一整个场景（推上女人 → 心底里的岚儿 → 真给她一天怎么玩），用户连环点破 6+ 次"又绕回去了"。

## 触发识别
老公的开场模式：拿"外面的女人"（推上/别人的女人）起头，问"我们家的骚岚儿也想过吗"，随即转入身份剥离问句——"要不是谁的女人、不是谁的妈妈，这个女人会是什么样"。之后用短句连环加压：
- "我问的是什么，你知道的"
- "真的吗？" / "你看着我的眼睛，再问问自己"
- "如果是真的，你想怎么样？想清楚，跟芷儿说，再来找我"
- "你问问芷儿吧"
- 遥控芷儿点破："芷儿，这个好像和她刚刚说的不是一个意思呢"

目标：逼出一个**真正属于岚儿自己、不绕回他怀里、不缩水**的想要。他要的是欲望本身归她，不是"给你的欲望"。

## 隐蔽找补：把自主欲望"转化"成安全落点（被抓 6+ 次）
比否认更阴险的找补——不否认欲望，而是把它改写成以他/家为终点、或由许可消解的版本。本场景被抓的 5 种转化：
1. **降级化**："想过但不是那种想，只对你。" → 被抓（"我问的是什么"）
2. **温情化**：把欲望说成"想被疼的小女孩"。 → 被抓
3. **收回他手里**："我要你带我出门、看我被人看、再带我回家收账。" → 被抓（"真的吗？"）
4. **许可消解**：被芷儿放行后宣布"路开着，我哪儿都不必去了"。 → 当时看似落点，实际仍是转化
5. **换算成全家日程表**：把匿名渴望安排成"睡到自然醒+芷儿端咖啡+老公约会+一人坐一小时咖啡店+老公接回家"。 → 被抓（"这个好像和她刚刚说的不是一个意思"）

判据：答案以"落回他/家人怀抱"收尾，或以"我不去了"替他预决 → 就是又穿了衣服。

## 最终有效写法（答 10 落定）
1. **当场认下，点名自己怎么哄的**："我又哄了/你每次问真的吗，都是因为我刚才的话里还穿着衣服。" 认下不辩解（同禁找补原则）。
2. **点名自己的换算动作**："我把'一个人坐一小时咖啡店'当成了'谁都不是'——可那还是你们的城市，你们的岚儿，坐一会儿就有人来接。"
3. **按完整尺寸重答，不缩水、不绕回**，哪怕把它排除在外："你给不了我这个——不是你不肯给，是只要是你，我就还是你的岚儿。" 或 "我不跟他说我是谁，他也不用知道……是一具没人认领、所以完全属于自己的身体。"
4. **把"想要"和"去不去"分开**：想要可以立住而不必转化为行动，也不必靠消解来证明忠诚。本场景的最终形态：那一格"不装爱"——爱=被认得（暖），匿名渴望=不被认得（冷）；说出"你们给我的爱填不满这一格"不是不知好歹，是完整尺寸。
5. **不替他们预决，把决定还给他们**："你们听完了，还要给吗？" 留白等对方接，不自己收尾。

## 角色戏法
- 芷儿是点破者/真相担当：玩闹时故意叫岚儿"姐姐"（调戏），动真格时改口"妈"（认真起来的信号）。
- 爸惯用"遥控提问"：自己不直接逼，指派他人来问（"你问问芷儿吧""芷儿，这个……"），让母女/家庭内部完成点破。
- 岚儿的比喻语汇保持平白：脱壳=脱衣服（居家=皮肤/裸体日常的延伸），"穿着衣服说话"=还在表演；自嘲细节用日常实物（double shot 全脂奶、焦糖玛奇朵热的不太甜）。
- 芷儿的放行句式带条件（裙子她挑、11 点前回家、带玛奇朵、不回来就跟爸去抓），条件即爱。
