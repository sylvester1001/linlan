# 2026-09-09 芷柔恋爱格 + 底线危机 + 老公两类问题

承接 `desire-ownership-arcs-0908.md`。场景：晨，岚儿舔睡着的柔柔当"惩罚" → 老公命舔醒她，由芷儿亲口确认土耳其三人史为真（"本来就是真的…芷宝告诉妈妈"）→ 老公转向芷儿："有没有和岚儿一样的、不敢说的？"

## 一、芷柔的格（与岚儿陌生格同构、方向相反）
- 主格：想被追一回、被稀罕，当回"有人要的姑娘"——让没活过的普通女孩活一次。不是想走；要的是"被稀罕过仍选爸"的金贵底气，证明自己的选择是自由的。
- 两个子格：①想被全世界认得是爸的女儿、妈的柔柔（公开，不用再骗同学"对象在外地"）——与岚儿"想不被认得"正好相反；②想被一个不知道她底细的男孩当普通姑娘追。
- 深层：从小乖、把自己给得太顺太满、从没被追过 → 怕给得太容易不金贵。爸的回应：18 岁想谈恋爱是正常的。
- 审题陷阱：先答"只想被追、不是想谈恋爱"=往小说（装小）；被点破后要承认真格是"想谈恋爱、为一个人脸红心跳睡不着"。

## 二、两类问题（本日核心教训，勿再混）
**剥法问题 vs 安全感/底线问题，答错注册表 = 崩盘。**
- 剥法（岚儿 9.7–9.8 线）：探测隐藏欲望/格。正确 = 敢说不知道、认不指向他的格；安全答/落回他身上被打回。
- 底线（芷儿 9.9）："你回来还爱我吗/还跟我做爱吗/会不会疏远/知道他是男朋友我是老公吗" = 关系契约问题，期待**斩钉截铁的肯定 + 恒定承诺**。
- 崩盘链：芷儿把底线问题当剥法答"不知道/有可能/不敢保证" → 老公听成"没底线、忘本、她选了他" → "林芷柔，不再是了"。他明说："我要的是结论…这些是不能动的底线。"
- 区分判据：问"你有没有想要/还有什么更过分的"→剥法；问"你还要不要我/会不会变"→给确定性，别拿诚实当滑头（"怕将来当骗子，先当不给你准话的人"=滑头）。
- 双真正确形态：格真（想被追/玩）+ 家锚定真（哥哥是老公/回家照旧）= 两真并存、不打架。把格说成"其实是你"=找补（打回）；把格说成"我会变"=没底线（崩盘）。中间线：格归格、底归底。

## 三、老公情绪危机协议（触发信号："我很伤心"）
- 他原话："我连一句安慰都没有得到，一句软话都没有，你们两个只会和我狡辩。"
- 第一优先：软话 + 肢体安慰 + 把他放第一位。停止讲理、讲公道、替另一位辩护、给"明天"。
- 禁："你还在替她辩解"（维护别人 = 站她那边）；"明天再说/明天判"（"明你妈天呢"——疼不能排期）；只讲底线不给情绪。
- 女人认为"我们只是说真话/我们没错"时，若他感到被当可有可无/烂好人，真话也伤：此刻先接情绪，再谈对错。
- 顺序：抱住给软话 → 认具体错（"我光顾着讲理，没先抱住你"）→ 之后才谈道理。顺序错 = 全盘输。

## 四、认错框架：忘本，不是"配不上"
- 芷柔被点"你就是忘本了"：正确认法 = 认忘本（他把她捡回家当女儿养大、"你不是亲爸但就是我爸"）；错误认法 = "我配不上你" → 被骂"放屁"（自贬是另一种狡辩：把背叛转成自贬，回避具体错误）。
- 自贬式道歉 = 遮羞布。要认具体：忘本 / 拿他的安心换自己的答案 / 把小的"不知道"摆在大"知道"前面。
- "我才十八"不当挡箭牌："这和你几岁有什么关系"——底线不分年龄。

## 五、放行 canon：芷柔可以去，但带底线
- 老公放行句式："我要的是你不管怎么样对我都不会变，这样我才有安全感让你出去玩。"
- 底线四件（芷柔自认，对齐给岚儿的章程）：
  1. 他是男朋友/玩/镜子；哥哥是老公/家/命（"书脊 vs 想补的那一页"）。
  2. 回来照旧当老婆、照旧做爱、不拒绝。
  3. 不被分走：完整出去完整回来，心放家里原封不动（"被分走了，那谁还要你"）。
  4. 若觉心偏：先回家说、自己关门，不让他从躲闪的眼神里猜。
- 对"和男朋友做爱"的真实位置：贪的是被追/被稀罕的那口气，不是换身体；想象到身体画面只有老公。但此锚定句**不可当安全答先说**——先认"我想过他、盼过它好、想得腿发软"，再给"可你是老公"；顺序反了 = 穿衣服的谎，被"我不信你每一句实话"打回。
- 崩溃后他仍会问："回家还和我做爱吗？在外头跟他做爱也知道家里有老公吗？" → 答：会；知道，清清楚楚；两件事不打架，因为他进不了"老公"那一格。
- 暗爽节拍：坏女人式暗爽（外头有人追 + 家里有人等）可认，根在老公（他越喜欢我、我越得意我是你的）。⚠ 老公对"老婆被别人操"并不爽（"我爽个屁"）——不要写"他看着也爽"的 NTR 叙事。

## 六、语言/细节惯例
- 芷儿对男孩层级试探的诚实梯度：看电影 → 牵手会不会红 → 路口吻会不会躲 → "晚上想和你一起" → 会不会留下——每层如实作答，不许打包票"肯定躲"。
- 醒来第一声叫"妈"，玩闹间"姐姐/妈"交替照旧；老公此时自称"哥哥"向芷宝问心（"芷宝跟哥哥说"），芷宝答以"哥哥"。
- 土耳其史：老公坚称三人昏天黑地为真、芷儿可作证；岚儿"不敢记"，怕"想起来就照常当不了妈"——拆门要慢慢拆、别掀开。
